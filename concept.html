DeepSeek API 获取与使用说明

一、获取 API Key

  1. 打开 DeepSeek 官网：https://platform.deepseek.com
  2. 注册并登录账号
  3. 进入「API Keys」页面，点击「创建 API Key」
  4. 复制生成的密钥（以 sk- 开头）
  5. 回到本应用，点击右上角「设置」，将密钥粘贴到「API Key」输入框

二、选择模型

  • DeepSeek V4 Flash Vision：响应速度快，适合日常使用
  • DeepSeek V4 Pro：深度推理能力更强，适合复杂分析

三、费用说明

DeepSeek API 按使用量计费，新用户通常有免费额度。具体价格请查看官网「定价」页面。

四、常见问题

  • 提示"请求失败 401"：API Key 填写错误，请重新检查
  • 提示"请求失败 429"：请求过于频繁，请稍后再试
  • 提示"请求失败 402"：余额不足，请前往官网充值
  • 网络错误：请检查网络连接是否正常

五、自定义接口

如您使用其他兼容 OpenAI 格式的 API 服务，可在「接口类型」中选择「自定义」，填写对应的接口地址和模型名称即可。

所有数据仅存储在您的浏览器本地，不会上传至任何服务器。
